# AltWing Video Studio

A 3D animated space-survival series created for AltWing.

## Project
THE LAST WING — Episode 1: The Signal

## Technology
- React
- TypeScript
- Remotion
- Three.js
- React Three Fiber

## Characters
- A mysterious astronaut in a matte-black spacesuit
- WING, a futuristic robotic penguin companion

## Goal
Create cinematic 3D animated episodes for Instagram Reels and YouTube Shorts, featuring interactive storytelling where viewers decide what happens next.

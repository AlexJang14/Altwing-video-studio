# The Last Wing — Don't Open the Door

This independent reset produces **only Episode 1**. Earlier compositions and
source files remain available. The film is 70 seconds, 1080 × 1920, 30 fps.
The audience chooses A or B; the film does not select an outcome.

Open the project with the existing Node dependencies:

```sh
npm ci
npm run typecheck
npm start
```

Select `Reset-Episode1` in Remotion Studio. Runtime assets, licensed narration
takes and the preview mix are included. Rebuilding Blender assets or downloading
a speech model is unnecessary for normal editing and rendering.

```sh
node scripts/reset_character_gate.mjs
npx tsx scripts/reset_motion_check.ts 2100
python3 scripts/reset_sound.py
node scripts/reset_render.mjs preview
node scripts/reset_render.mjs final
```

The sound builder needs Python and NumPy. It writes a continuous lossless audio
master to `work/reset/audio/master.wav`; `assemble_reset.py` uses that master
when joining CI frame ranges. Final video uses H.264, yuv420p, Rec.709 and AAC.
The Actions workflow renders seven consecutive 300-frame ranges. Preview mode
uses 270 × 480; final mode renders natively at 1080 × 1920. It never launches
the earlier Episode 2 or 3 compositions.

The editable character scene is `public/reset/reset-characters.blend` with
relative texture links. Modeling recipes are `scripts/build_reset_characters.py`
and `scripts/build_reset_environment.py` (Blender 4.3). Deterministic rigs and
blocking are in `src/reset/rig.ts` and `motion.ts`. Cameras, sets, overlays and
the actual separate cockpit-camera composition are in the same directory.

`episode.json` contains the shot plan and exact narration. Actual take timing,
24 phrase captions, SRT and the spoken script are in `public/reset`. The
short future narrative is in `docs/reset/STORY-BIBLE.md`.

The narrator is the stock American male `am_michael` from Kokoro 82M, produced
locally with Kokoro ONNX. The model is Apache-2.0; the runtime is MIT. See
`LICENSES.md`. The 13 WAV takes are included so the project can be edited without
installing TTS. `reset_voice.py` records the synthesis recipe. Original sound
effects and the small companion motif are generated by `reset_sound.py`.

The Lost Sensor footage is captured from the user's official public AltWing
site. Its real simulation slider moves; no fictional door game, fabricated
feature or invented statistic is shown. `product-provenance.json` records the
URL, capture method and date. The official penguin brand asset is reused from
the prior verified capture in `public/brand`.

Limitations remain explicit: the definitive physical plush photograph was not
attached, so exact likeness could not be verified. The style is a compact,
procedurally animated 3D production. Linked reference media could not be played
in this environment, and the narrator was not independently assessed by ear.
The QC report distinguishes measured technical checks from subjective goals.

Large finished films belong in downloadable delivery assets, not ordinary Git
history. The source ZIP includes the editable project and reusable assets.

# Asset provenance

- `src/rescue/Wangdoo.tsx`: original procedural plush reconstruction from the written gray/white plush description and earlier smiling penguin reference. The newer actual plush photograph mentioned in the brief was not attached. No claim of exact matching is made.
- `public/models/wangdoo-plush-mentor.glb`: exported from that same source rig. Six baked mentor cycles; validated as a usable model. Existing robot/soft models remain preserved for earlier films.
- `public/rescue/memory-plush.png`, `memory-training.png`: original rendered fictional in-universe archives. These do not portray or document the user's personal history.
- `public/rescue/security.mp4`, `security-poster.png`: original 3D security footage using the current astronaut, plush and station. The 15-fps surveillance footage is intentionally lower cadence within the 30-fps main film.
- `public/rescue/warning.mp4`, `warning-poster.png`: original rendered fictional mission archive, featuring the matching astronaut sending the warning. No external person or recording is used.
- `public/rescue/altwing-aerospace.png`, `altwing-power.png`, `altwing-sensor.png`: authentic unmodified public AltWing activity views. Official routes and capture evidence are in `public/rescue/verified-activities.json`. No fabricated product features, user/account data or paid source.
- `public/audio/rescue/episode-1/2/3.mp3`: deterministic original synthesis from `scripts/rescue_audio.py`, including music, air, pressure, footsteps, mechanical effects and nonverbal chirps. No speech. Earlier voiced assets are used only by earlier compositions.
- Existing astronaut, spacecraft, station, alien vegetation, gate and lighting code are reused from this same project. New rescue-specific terrain and shelter geometry are procedural. Shared changes preserve the old action API and optional original scene behavior; archive branches retain earlier source snapshots.
- Bundled DejaVu fonts retain their existing notices. No additional font installation, stock-media purchase, speech service or paid rendering API was used.

The new source is on `codex/master-narrative`; previous cinematic source is preserved on `archive/cinematic-before-master-narrative`. Previous published deliveries remain on their own branches. Native rendering uses standard GitHub Linux runners and the existing lockfile.
